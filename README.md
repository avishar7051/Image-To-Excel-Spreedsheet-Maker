# 📊 Image to Excel Spreadsheet Maker

An AI-powered web application built with Google Gemini Vision to automatically extract tabular data, multi-column sections, invoices, receipts, and structured text from images directly into organized, downloadable Excel (`.xlsx`) spreadsheets.

---

## ✨ Features

- **Multimodal AI Extraction:** Powered by Google Gemini to analyze tables, headers, and rows from messy or complex images.
- **Multi-Section Detection:** Automatically separates multiple tables or sections into structured groups or distinct sheets.
- **Interactive In-Browser Editor:** Preview and edit detected rows, headers, and values before exporting.
- **Instant Excel Export:** Direct client-side `.xlsx` generation using SheetJS (`xlsx`) with formatted column widths and sheet naming.
- **Drag-and-Drop Interface:** Quick uploads with instant image preview.

---

## 🛠️️ Tech Stack

- **Frontend:** React, Tailwind CSS
- **AI Engine:** Google Gemini API (Multimodal Vision)
- **Spreadsheet Generation:** SheetJS (`xlsx`)
- **Icons & UI:** Lucide React
